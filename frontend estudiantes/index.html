Sobre esta versión

Estas pantallas usan HTML, CSS y JavaScript. El registro, la búsqueda y la modificación llaman a una API local en C++, que realiza las operaciones en PostgreSQL una vez configurado e iniciado el servidor.

La interfaz toma como referencia la estructura real de DBAcademiaUltimate.
